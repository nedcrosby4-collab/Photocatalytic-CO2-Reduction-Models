# Photocatalytic-CO2-Reduction-Models
Code and data for: "Multi-Output Machine Learning for Photocatalytic CO2 Reduction and Inverse Catalyst Design" - MEng Report, Durham University Department of Engineering 2026.

## Overview
The PRIDMO dataset combines catalyst compositional properties with experimentally reported reaction conditions and product yields and identities.
A random forest and neural network model are included, along with inverse design tools for both models. These can all be found in main

## Data
See data folder, includes PRIDMO datset, IIT Madras validation experiment, Ozsoysal et al. dataset, periodic table and precached materials project data.
